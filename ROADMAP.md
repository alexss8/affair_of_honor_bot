### 6A. База не растёт

Принцип: в БД хранится только то, что нужно сейчас. Таблица `stats` (рейтинг для топа) — единственное, что хранится бессрочно: одна строка на игрока в чате, обновляется на месте.

- [ ] 6.9 Запись из `bot_messages` удаляется сразу после удаления сообщения в Telegram (и после неудачной попытки, если сообщение уже недоступно или старше 48 ч)
- [ ] 6.10 `duels_history`: хранить только последние N дней (`HISTORY_RETENTION_DAYS`, по умолчанию 30) — нужна только для номера дуэли и статистики «за сегодня»; номер дуэли продолжает расти (AUTOINCREMENT)
- [ ] 6.11 `chat_users`: колонка `last_seen`, удалять записи, не обновлявшиеся N дней (`USER_CACHE_RETENTION_DAYS`, по умолчанию 90)
- [ ] 6.12 Файл БД не раздувается: `PRAGMA auto_vacuum=INCREMENTAL` (через миграцию с разовым `VACUUM`) + `PRAGMA incremental_vacuum` после чистки; `PRAGMA wal_checkpoint(TRUNCATE)` и `journal_size_limit`, чтобы WAL-файл не рос
- [ ] 6.13 Топ всегда актуален: формируется из `stats` в момент отправки; чистка истории/кэша не влияет на рейтинг
