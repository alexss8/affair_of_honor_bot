# 🚀 Инструкция по развертыванию и управлению ботом (Ubuntu 22.04)

Этот документ описывает пошаговый перенос проекта на VPS-сервер под управлением **Ubuntu 22.04**, настройку безопасности, запуск в фоновом режиме 24/7 и дальнейшее обновление.

---

## 1. Подготовка перед отправкой (на вашем компьютере)

1. Остановите локально запущенного бота (`Ctrl + C` в терминале), чтобы избежать конфликта токенов (`TelegramConflictError`).
2. Убедитесь, что в папке проекта **нет** локальных временных файлов (если есть — удалите их перед копированием):
   - `.env`
   - `duels.db`, `duels.db-wal`, `duels.db-shm`
   - `bot.log`
   - папка `.pytest_cache` или `__pycache__`
3. Убедитесь, что в `@BotFather` для бота включена работа в группах и отключен режим приватности, чтобы бот мог запоминать участников по `@username`:
   - `/mybots` -> выберите бота -> **Bot Settings** -> **Group Privacy** -> **Turn off**.
   - *(Если бот уже был добавлен в группу до смены этой настройки — удалите его из группы и добавьте заново).*

```bash
scp -r C:\Users\alexfrostss8\Desktop\duel_bot root@ВАШ_IP_СЕРВЕРА:/root/
```

---

## 3. Автоматическая установка и запуск (на сервере)

1. Подключитесь к серверу по SSH:
   ```bash
   ssh root@ВАШ_IP_СЕРВЕРА
   ```
2. Запустите скрипт автоматического развертывания:
   ```bash
   bash /root/duel_bot/deploy.sh
   ```
3. Скрипт автоматически:
   - Установит **Python 3.12** и системные зависимости.
   - Настроит фаервол **UFW** (закроет все входящие порты, кроме SSH).
   - Создаст изолированного пользователя `botuser` без прав `root` и перенесет код в `/home/botuser/duel_bot`.
   - Создаст виртуальное окружение `venv` и установит библиотеки из `requirements.txt`.
   - Запустит интерактивный мастер `setup_env.py` — **вставьте ваш `BOT_TOKEN`** (ввод скрыт на экране) и нажмите `Enter` для подтверждения стандартных настроек (`DEFAULT_HP=5`, `TOP_LIMIT=10` и т.д.).
   - Настроит и запустит системную службу `duelbot.service` для круглосуточной работы 24/7.

4. После завершения удалите исходную копию из `/root`:
   ```bash
   rm -rf /root/duel_bot
   ```

---

## 4. Управление ботом и диагностика

Все команды выполняются на сервере от имени `root` (или через `sudo`):

* **Проверить статус работы:**
  ```bash
  systemctl status duelbot
  ```
  *(Должен отображаться зеленый статус `active (running)`).*

* **Посмотреть живые логи в реальном времени:**
  ```bash
  journalctl -u duelbot -f
  ```
  *(Для выхода из просмотра нажмите `Ctrl + C`).*

* **Перезапустить бота (например, после правки `.env`):**
  ```bash
  systemctl restart duelbot
  ```

* **Остановить бота:**
  ```bash
  systemctl stop duelbot
  ```

---

## 5. Как обновить код бота в будущем (без потери базы данных)

Если вы изменили код или добавили новые фразы в `phrases.py` на компьютере:

1. Скопируйте обновленные `.py` файлы на сервер с компьютера:
   ```bash
   scp C:\Users\alexfrostss8\Desktop\duel_bot\*.py root@ВАШ_IP_СЕРВЕРА:/home/botuser/duel_bot/
   ```
2. На сервере обновите права и перезапустите службу (база `duels.db` и файл `.env` останутся нетронутыми):
   ```bash
   chown -R botuser:botuser /home/botuser/duel_bot
   systemctl restart duelbot
   ```

---

## 6. Резервное копирование базы данных (Бэкап)

База данных SQLite работает в режиме **WAL**, поэтому состоит из трех файлов (`duels.db`, `duels.db-wal`, `duels.db-shm`). Чтобы сделать безопасный бэкап:

```bash
systemctl stop duelbot
cp /home/botuser/duel_bot/duels.db /root/duels_backup_\$(date +%F).db
systemctl start duelbot
```
