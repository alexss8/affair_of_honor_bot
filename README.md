# ⚔️ Affair of Honor — Дуэльный Telegram-бот

Асинхронный Telegram-бот для проведения интерактивных пошаговых дуэлей в групповых чатах и сообществах (включая супергруппы с темами/форумами). Разработан на базе **aiogram 3** и **SQLite (WAL)** с соблюдением принципов SOLID и KISS.

---

## 🎮 Возможности

- **Пошаговая боевая система:** Игроки по очереди атакуют и защищаются по двум уровням (верхний и нижний) вслепую через Inline-кнопки.
- **Гибкий вызов на бой:** Можно вызвать соперника по упоминанию (`/duel @username`) или ответом (**Reply**) на любое его сообщение (`/duel`).
- **Атмосферный отыгрыш:** Более 100 уникальных боевых реплик для атак и парирований, динамическая индикация ожидания хода, фаза броска кубиков и двойное подтверждение капитуляции.
- **Единый рейтинг чата (`/top`):** Таблица лидеров с подсчетом побед, поражений и винрейта.
- **Безопасность и отказоустойчивость:** Защита от двойных нажатий, флуд-контроля Telegram (429), удаления сообщений во время боя, а также команда `/cancel` для аннулирования зависших дуэлей.
- **Высокая производительность:** Фоновая очередь записи (`asyncio.Queue`) с батчингом и SQLite в режиме `WAL` (протестировано на 500 одновременных дуэлях).

---

## 🛠 Команды бота

| Команда | Описание |
| :--- | :--- |
| `/duel @ник` или `Reply` | Вызвать участника чата на дуэль |
| `/cancel` | Отменить свой текущий бой без изменения рейтинга |
| `/top` | Показать таблицу лидеров чата |
| `/help` | Вывести правила игры и список команд |

## 💻 Локальный запуск и тестирование

1. **Установите зависимости** (требуется Python 3.12+):
   ```bash
   pip install -r requirements.txt
   ```

2. **Сгенерируйте файл настроек `.env`:**
   ```bash
   python setup_env.py
   ```
   *(Укажите ваш токен от `@BotFather` и подтвердите стандартные параметры).*

3. **Запустите автотесты** (опционально, требует `pytest` и `pytest-asyncio`):
   ```bash
   pytest -v
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```

Подробная инструкция по переносу проекта на VPS, настройке фаервола, прав доступа и запуску в фоновом режиме 24/7 через `systemd` находится в файле **[DEPLOY.md](DEPLOY.md)**.
