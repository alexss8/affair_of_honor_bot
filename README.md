# ⚔️ Affair of Honor

Интерактивный Telegram-бот для проведения пошаговых дуэлей в групповых чатах и супергруппах с темами (Topics).

---

## 🎮 Возможности

- **Пошаговые дуэли вслепую:** Игроки по очереди атакуют и защищаются по двум уровням (верхний и нижний) через Inline-кнопки без засорения ленты лишними сообщениями.
- **Удобный вызов на бой:** Поддерживается вызов по упоминанию (`/duel @username`) и ответом (**Reply**) на сообщение соперника, а также отзыв вызова кнопкой до начала боя.
- **Атмосферный отыгрыш:** Более 100 уникальных реплик для ударов и блоков, индикация ожидания хода на кнопке и двойное подтверждение сдачи.
- **Рейтинг чата:** Общая таблица лидеров с подсчетом побед, поражений и винрейта (`/top`).
- **Отказоустойчивость:** Защита от спама кликами, флуд-контроля Telegram, удаления сообщений во время боя, а также команда `/cancel` для отмены зависших дуэлей.

---

## 🛠 Команды бота

| Команда | Описание |
| :--- | :--- |
| `/duel @ник` или `Reply` | Вызвать участника чата на дуэль |
| `/cancel` | Отменить свой текущий бой без изменения рейтинга |
| `/top` | Показать таблицу лидеров чата |
| `/help` | Вывести правила игры и список команд |

## 🚀 Быстрый старт

**Требования:** Python 3.12+

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройте окружение:**
   ```bash
   python scripts/setup_env.py
   ```
   *(Интерактивный мастер запросит `BOT_TOKEN` от `@BotFather` и создаст файл `.env`).*

3. **Запустите бота:**
   ```bash
   python -m bot
   ```

```

├── domain/                # игровая логика без aiogram и БД: models, engine, phrases

    ├── duel_cards.py      # правки карточки боя под блокировкой
    ├── duel_timer.py      # таймаут дуэли
    ├── handlers/          # common, invite, battle, admin, errors, fallback
    └── ui/                # texts, keyboards
```

## ⚙️ Переменные окружения

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `BOT_TOKEN` | — | **Обязательно.** Токен бота от `@BotFather` |
| `ADMIN_ID` | — | Числовой Telegram ID администратора для доступа к `/status` и алертам |
| `DEFAULT_HP` | `5` | Количество жизней у каждого бойца |
| `TOP_LIMIT` | `10` | Количество позиций в таблице лидеров `/top` |
| `DUEL_TIMEOUT_SEC` | `300` | Длительность дуэли в секундах; по истечении побеждает боец с большим запасом жизней |
| `INVITE_TTL_SEC` | `300` | Сколько секунд действует вызов на дуэль |
| `DB_PATH` | `duels.db` | Путь к файлу базы данных SQLite |
| `LOG_FILE` | `bot.log` | Путь к файлу логов |
